# تطبيق المرافق (Al-Murafiq) — جاهز للاستضافة والتثبيت على الجوال (PWA)

## كيف يفتحه الزبون على تلفونه ويثبته؟
التطبيق مهيأ كـ **Progressive Web App (PWA)** بمجرد رفعه على استضافة تدعم **Node.js** مع رابط **HTTPS**:
1. ترسل للزبون رابط الموقع + **كود الـ PNR** + **اسم العائلة**.
2. يفتح الرابط من متصفح جواله:
   - **أندرويد (Chrome):** يظهر زر **"تثبيت التطبيق"** في الأعلى أو من قائمة المتصفح *"إضافة إلى الشاشة الرئيسية"*.
   - **آيفون (Safari):** يضغط زر **المشاركة (Share)** ثم يختار **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليظهر كأيقونة تطبيق على جواله.

## أسهل استضافة لرفعه أونلاين:
- **Render.com** أو **Railway.app** أو **Fly.io** (تدعم خوادم Node.js وقاعدة البيانات مباشرة):
  1. ارفع ملفات المشروع إلى **GitHub** أو اربط المجلد مباشرة بالمنصة.
  2. اجعل أمر البناء (Build Command): `npm install`
  3. اجعل أمر التشغيل (Start Command): `npm start`
  4. بعد النشر ستحصل على رابط عام (`https://...`) ترسله للزبائن فوراً.
