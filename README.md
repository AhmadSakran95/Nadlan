# Nadlantours - تطبيق إدارة وبرامج السياحة والسفر

تطبيق ويب متكامل باللغة العربية (RTL) لإدارة حجوزات السفر وعرض البرامج السياحية للزبائن مع دليل وجهة تلقائي ومساعد ذكي (AI).

## محتويات الحزمة (ZIP)
- `index.html`: الواجهة الرئيسية للتطبيق (قسم حجز الزبون + قسم الإدارة).
- `styles.css`: التنسيقات الإضافية والخطوط العربية.
- `app.js`: منطق التطبيق الكامل، إدارة الحجوزات، توليد أرقام PNR، جلب الطقس المباشر لـ 5 أيام، قاعدة بيانات فيوز الكهرباء والمطاعم الحلال، والمساعد الذكي.
- `README.md`: دليل الاستخدام السريع.

## طريقة التشغيل
1. فك الضغط عن الملف.
2. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Safari).

## بيانات الدخول التجريبية
- **قسم الإدارة:** رمز المرور `1234` (أو اضغط على زر الدخول السريع).
- **قسم الزبون:**
  - `PNR`: **NDL101** | اسم العائلة: **المنصور** (برشلونة)
  - `PNR`: **NDL202** | اسم العائلة: **العلي** (إسطنبول)
  - `PNR`: **NDL303** | اسم العائلة: **الخالدي** (دبي)
